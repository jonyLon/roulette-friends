# Рулетка з друзями

Американська рулетка 0/00 на віртуальні фішки. До восьми гравців у кімнаті, спільні раунди, серверний випадковий результат, баланс і історія у D1. Кімнати захищено випадковим кодом, гравців — випадковим токеном браузера. Зберігайте посилання на кімнату для повернення. Господар запускає й відкриває раунди; для зміни господаря створіть нову кімнату.

## Локальний запуск

1. `npm install`
2. `npx wrangler d1 migrations apply roulette-local --local`
3. `npx wrangler dev --port 8787`

`npm test` перевіряє виплати, спільні раунди, повторні запити та повернення ставок. `npm run build` готує Cloudflare Worker для Sites. Зміни схеми: `npx drizzle-kit generate`.

Ставки на окремі числа, кольори, парність, половини, дюжини та колонки. Ставки між числами не реалізовані. Це стилізований вигляд зверху за референсом, без персонажів і 3D-сцени оригінальної гри. Справжні гроші не використовуються.
