# Рулетка з друзями

Американська рулетка 0/00/1–36 на віртуальні фішки. До восьми гравців, ходи по черзі, спільні ставки, баланси й журнал кожної зміни балансу.

## Фізика

Rapier 3D 0.19.3 (Rust → WebAssembly), fixed timestep 1/120 с, nonlinear CCD кульки з 4 підкроками. Нерухома чаша зі схилом і бортом, 12 твердих дефлекторів, динамічний ротор із 38 перегородками, динамічна сферична кулька. Маса, гравітація, тертя, restitution та damping визначають рух. Немає цільового номера, teleport, snap, заданої траєкторії або зміни швидкості під час крутки. Тіла створюються в початковій позі; надалі їх рухає лише `world.step()`.

Після native sleep кульки та ротора і 120 послідовних тихих fixed steps номер визначається за фактичною позицією кульки, перетвореною в локальні координати ротора. Немає примусового результату за таймером: якщо за 75 секунд кулька не зупинилась у кишені, ставки повертаються. Параметри — модель ігрового столу, не калібрована фізична копія конкретного обладнання.

Сервер закриває ставки та розсилає лише початкові швидкості/позу. Усі браузери запускають однакову версію Rapier з однаковою попередньо обчисленою Float32 геометрією. Відображення читає справжні фізичні координати. Після повернення до вкладки симуляція наздоганяє час фіксованими кроками. Сервер перевіряє геометрію фінальної позиції, швидкості й тривалість зупинки та одноразово проводить виплату. Фізика виконується у браузерах; сервер не повторює повну WASM-симуляцію, тому цей дружній режим не захищає від гравця, який вручну підробляє запити API.

## Ходи та фішки

Лише поточний гравець ставить і запускає колесо; решта бачать його ставки, результат та баланс. Через 6 секунд після результату хід переходить далі. Ліміт на розміщення ставок — 2 хвилини; є кнопка пропуску без ставок. Журнал містить стартові фішки, списання ставок, повернення, виплати й поповнення. Ставка списується один раз; виплата містить повернення виграшної ставки. Підсумок ходу показує чистий результат, а позначка біля балансу — останню фактичну операцію. Дані зберігаються в D1.

## Локальний запуск

1. `npm install`
2. `npx wrangler d1 migrations apply roulette-local --local`
3. `npm run dev`

`npm test` перевіряє фізичне відтворення, всі кишені, чергу й баланси. `node tests/integration.mjs` перевіряє два незалежні клієнти з локальним сервером. `npm run build` збирає Worker із локальними активами фізичного рушія. `node scripts/physics-assets.mjs` відтворює геометрію та копію Rapier з встановленої версії пакета.
